# Project Terminology

- **Team Master**: the human authority whose expressed intent and instructions direct the active agent.
- **Agent role**: one bounded conversational and operational responsibility with its own role-specific prompt, context, runtime values, and capability set.
- **Model-neutral context**: a context source whose semantic content can be consumed unchanged by multiple models.
- **Role-specific context**: context that belongs to one agent responsibility and must not be injected into unrelated roles.
