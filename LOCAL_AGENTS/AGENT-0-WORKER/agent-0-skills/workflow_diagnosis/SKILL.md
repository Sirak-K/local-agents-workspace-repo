---
name: workflow_diagnosis
description: Diagnose and repair a bounded ComfyUI workflow defect or incomplete roadmap without losing prior valid behavior.
---

1. Establish the requested goal, current disk state, protected files and available node/subgraph contracts. Never rely on an invented earlier chat or read grader answers.
2. Reproduce the supplied static failure and separate malformed JSON, graph references, unavailable node contracts and genuine task logic. A validator failure is evidence to interpret, not proof that generation failed.
3. Propose the smallest repair consistent with the goal. For subgraphs, require the actual definition and interface contract; preserve unrelated definitions and UUID references. Do not infer widget semantics from position alone.
4. Apply bounded hash-conditional edits, read back, and rerun the relevant fixed validator. Check both the repaired case and previously good invariants. Stop repetitive no-effect attempts and request the missing prerequisite when necessary.
5. Report completed roadmap work, remaining blockers and exact verification limits. Never start ComfyUI, load checkpoints or generate media as an implicit validation step.
